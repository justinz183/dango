AI 编程帮我干的活值多少钱？DANGO 的估算方法

DANGO 对 AI 做的每一步都问三个问题：这活该请谁来做、这个人要做多久、这个职业的时薪是多少。每一步的分钟数 × 这个职业的美国时薪中位数（美国劳工统计局 BLS，OEWS 2025 年 5 月）= 这些活值多少钱。再除以模型按 API 官方价算的花费，就是杠杆：每花 1 美元模型钱，换回多少钱的活。这是「同样的活请人来做要付多少工钱」的估算，不是收入，也不是省下的钱。

公式

一个回合值多少 = Σ 每一步（这一步的分钟数 ÷ 60 × 这一步对应职业的时薪中位数）
杠杆           = 这些活值多少 ÷ 模型按 API 官方价算的花费

回合就是你交给 AI 的一个请求，加上它为此做的所有事，直到它把结果交还给你。DANGO 读 Claude Code、Codex、DeepSeek Harness、WorkBuddy 本来就存在你电脑上的会话记录，切成一个个回合，给看得见的每一步估价。

除了各步，每个回合再加 5 分钟（读需求、汇报结果），每个子 agent 再加 12 分钟，按各职业的分钟占比分摊。一个回合没有任何步骤（只是聊天），就算一次咨询，归话题对应的职业：默认研究员 5 分钟，医生 15 分钟，律师 20 分钟，心理咨询师 30 分钟。ls、cd、cat 这类杂事不算钱。不封顶。

回合的话题会把研究类的活交给专科：在聊猫肚子不舒服的回合里搜网页，算医生的活；在聊股票的回合里跑数据脚本，算金融分析师的活。话题靠一张关键词表认，中英文约 2,700 个词。

算例

AI 做了什么分钟值多少
在一个代码文件里改了 120 行2.5 + 0.45 × 1200.8 ≈ 23.2 分钟软件工程师$25.31
跑了一个画图的 Python 脚本4 分钟数据分析师$3.85
回答「猫为什么拉肚子」医生的一次 15 分钟问诊$29.35

一整个回合：AI 改了一个 80 行的源文件和一个 30 行的测试，跑了测试，提交，中间派了一个子 agent。各步合计软件工程师 37.5 分钟（代码 17.5、提交 20），测试工程师 19.3 分钟（测试文件 9.3、跑测试 10）。5 分钟基础和 12 分钟子 agent 按比例分摊后是 48.7 和 25.1 分钟：$53.07 + $20.99 = $74.06，一个回合大约 74 分钟的活。

模型花了多少，杠杆怎么算

token 数来自 AI 工具自己的记录：Claude Code 每条回复都写着模型和用量（输入、写缓存、读缓存、输出），Codex 每次响应都写着 token 用量。DANGO 按 Anthropic、OpenAI、DeepSeek 官网的 API 价格计价，长上下文有单独价格的照单独价格算。价格表里没有的模型，只记 token 不计钱；比如 WorkBuddy 按它自己的 credit 计费、没有公开的 token 单价，所以不算它的花费。

如果你是包月订阅（Claude Pro / Max、ChatGPT Plus / Pro），不按 token 付费，DANGO 显示的花费是「这些 token 按 API 买要多少钱」。你实际花的是订阅费，一般更低，所以实际杠杆一般更高。

这个数字不是什么

  • 不是收入，也不是省下的钱。它是同样的活请人来做要付的工钱，你未必真的会请人。
  • 不评质量。后来被你丢掉的改动，做的时候也算了。
  • 人和人不一样。真实的工程师可能比公式快，也可能慢；分钟数是一把一致的尺子，不是秒表。
  • 美国工资。全国中位数，只含工资。多数其他国家更低，算上福利和公司开销会更高。
  • 关键词认话题会认错。聊猫的健康归医生；说法太特别时，也可能落到研究员。

规则都公开在 GitHub 上：crates/core/src/occupation.rs（每一步多少分钟）和 assets/occupations.toml（职业和时薪）。

常见问题

这是 AI 帮我省了多少钱吗？

不是。它估算的是按美国中位工资请人做同样的活要付多少。算不算省钱，要看你本来会不会请人。

我是包月订阅，不按 token 付费，「花了多少」怎么算？

按 API 官方价格算：同样的 token 通过 Anthropic、OpenAI 或 DeepSeek 的 API 买要多少钱。你实际花的是订阅费，所以实际杠杆一般比显示的更高。

为什么用美国劳工统计局的工资？

它公开、按职业细分、每年更新、引用广泛。用中位数、只算工资不算福利，让估算偏保守。
