隐私说明：DANGO 读哪些文件、记哪些字段、从来不做什么

DANGO 全部在你的电脑上运行，什么都不上传。它读 Claude Code、Codex、DeepSeek Harness、WorkBuddy 本来就写在你用户目录里的会话记录，换算成数字（分钟、回合、改了多少行、归哪个岗位、token 和花费），存进本机的数据库。App 里没有账号、没有遥测、没有统计。

读哪些文件

只读这些 AI 工具给自己留的记录，不往 Claude Code、Codex 里装任何东西。

工具文件用来做什么
Claude Code~/.claude/projects/会话记录（含子 agent）：做了哪些步骤、改了多少行、用的模型和 token
~/.claude/sessions/正在跑的会话是在干、干完了，还是在等你批准
~/.claude/settings.json只看 DANGO 自己的 Claude Code 插件开没开，免得重复计
Codex~/.codex/sessions/、~/.codex/archived_sessions/会话记录：做了哪些步骤、token 用量
~/.codex/session_index.jsonlCodex 给对话起的名字，给你的报告窗口用
DeepSeek Harness~/.dsh/sessions/会话记录
WorkBuddy~/.workbuddy/projects/、~/.workbuddy-ai/projects/会话记录

Windows 上是 %USERPROFILE% 下的同名文件夹。

记下哪些

一个 SQLite 数据库，在 ~/.dango/data.db（Windows 是 %USERPROFILE%\.dango），只有你的用户账号能读：

  • 每个回合：开始和结束时间、哪个 AI 工具、动了几个文件、新增和删除了多少行、有没有跑测试、过没过、有没有提交或合并、几个子 agent、每个岗位多少分钟和值多少钱、每个模型的 token 和按 API 价算的花费。
  • 每个会话：开始和结束时间、活跃分钟，以及工作文件夹的 12 位 SHA-256 指纹（存指纹，不存路径）。
  • 会话标题和项目文件夹名：从 AI 工具自己的记录里读，给你 Mac 上的报告窗口列出「做了哪些事」。只留在你的电脑上，分享卡上从来没有。

除此之外存下的每一段文字都必须是短标记（ID、哈希、固定取值）。项目里带一个检查命令 dango privacy-scan：存下的东西里只要有数字和短标记以外的内容，就报错。

从来不做什么

  • 上传任何东西：后台服务没有联网代码，也不开网络端口
  • 账号、登录、遥测、统计、崩溃上报
  • 排行榜，或者拿你和别人比
  • 改你的 Claude Code、Codex 设置

分享卡

分享卡（日报、周报、月报、年报、总计）上只有数字、岗位和你的 ABTI 人格，从来没有项目名和会话标题。只有你自己点分享，卡片才会离开你的 Mac。

彻底删掉

Mac 上先从右键菜单退出 DANGO，再在终端里运行：

launchctl bootout gui/$(id -u)/com.dango.daemon 2>/dev/null
launchctl bootout gui/$(id -u)/com.dango.widget 2>/dev/null
rm -f ~/Library/LaunchAgents/com.dango.daemon.plist ~/Library/LaunchAgents/com.dango.widget.plist
rm -rf /Applications/Dango.app ~/Applications/Dango.app ~/.dango

Windows 上在「设置 → 应用」里卸载 Dango，再删掉 %USERPROFILE%\.dango。两种情况都不会动你 Claude Code、Codex 的记录。

官网

dangoai.org 不设 cookie，也不放统计代码。首页的字体从 Google Fonts 加载。下载量我们只看 GitHub 上每个版本公开显示的下载次数。

常见问题

DANGO 会上传我的代码或对话吗？

不会。全部在你的电脑上计算，什么都不发出去。

DANGO 需要账号或者联网吗？

不需要。没有账号，断网也能用。后台服务里根本没有联网的代码。

我能自己核实吗？

能。源代码在 GitHub（github.com/justinz183/dango），数据库就是 ~/.dango 里一个普通的 SQLite 文件，dango privacy-scan 会检查里面只有数字和短标记。
