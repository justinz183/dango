Mac 上有哪些 Claude Code、Codex 的菜单栏工具

大多数 Claude Code 菜单栏工具是额度表：CodexBar、ClaudeBar、Claude Usage Tracker、Usage4Claude、Claude Usage Bar 显示 5 小时和每周额度用了多少、什么时候重置；CodexBar 和 ClaudeBar 还支持 Codex 和很多别的服务。CCSeva 主要看 Claude Code 的 token 和花费。DANGO 回答的是另一个问题：Claude Code、Codex、DeepSeek、WorkBuddy 替你干了多少活，按 API 价花了多少，同样的活请人来做要多少钱。老是撞额度，就选额度表；想知道 AI 值不值，就选 DANGO。

看额度、看花费，还是看值不值？

  • 「我是不是快撞额度了？」用额度表。它从服务商那里读你套餐的用量，显示进度条和重置时间。多个工具一起用选 CodexBar、ClaudeBar；只用 Claude 选 Claude Usage Tracker、Usage4Claude 或 Claude Usage Bar。
  • 「我用了多少 token，按价算多少钱？」用读记录的工具：菜单栏里的 CCSeva，或者命令行的 ccusage。见怎么看 Claude Code、Codex 花了多少钱。
  • 「值不值？AI 到底替我干了什么？」用 DANGO。它把 AI 的每一步归到一个岗位（代码归软件工程师，图表归数据分析师，查资料归研究员），按这个岗位的美国时薪中位数计价，再和模型花费放在一起比。怎么估算的 →

常见问题

Mac 上有看 Claude Code 用量的菜单栏工具吗？

有好几个。CodexBar、ClaudeBar、Claude Usage Tracker、Usage4Claude、Claude Usage Bar 看套餐额度；CCSeva 看 token 和花费；DANGO 看干了多少活、按美国中位时薪值多少钱，以及模型花费。

哪个菜单栏工具同时支持 Claude Code 和 Codex？

CodexBar、ClaudeBar、Usage4Claude 和 DANGO 都支持；Claude Usage Tracker 从 3.3 版起也支持 Codex。

这些工具会上传我的数据吗？

额度表要向服务商查你的用量，所以会用你的账号和 Anthropic 或 OpenAI 通信。DANGO 只读本机的记录文件，什么都不上传。
