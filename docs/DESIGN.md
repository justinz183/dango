# ShadowCorp 设计稿 v2 — 你的 Claude，和它的工作日报

2026-10-29。替代 docs/SPEC.md 第 1、6–10 节的"影子公司"设定；计分引擎（§4–5）不变。

## 一句话

ShadowCorp 是住在屏幕角落的"你的 Claude"：它记得自己替你干了多少活、什么时候干的、干的是哪一类事，每天、每周、每月给你写一份好看到能发出去的工作报告。

## 1. 钱的问题：$80/小时怎么来的，为什么要换掉

$80 是我按"美国软件工程师全包用人成本 ÷ 年工时"粗估的数，不是查出来的，也不该当标准。更大的问题是：**任何时薪都会让人先质疑数字，再看内容**。

改法：

| 原来 | 现在 |
| --- | --- |
| 头条是 $ | 头条是**人类等价工时**：「今天我替你干了 16.5 小时的活」。这是引擎本来就算的量（SPEC §5.3 的 H），参考 Anthropic Economic Index 的口径 |
| XP 由分钟换算 | 不变：1 XP = 1 分钟等价工时，段位不变 |
| $ 永远显示 | `[value] hourly_rate_usd` 默认 0 = 不显示。想看钱的人填自己的数，卡片上就多一行「≈ $1,322」 |

杠杆率保留：「你花了 2.4 小时，它干了 16.5 小时的活，杠杆 6.9x」——这是最能说明"用得巧"的数。

## 2. 角色：你的 Claude

不是公司员工，就是 Claude 本人——一个圆滚滚的墨团，两只大眼睛，住在小部件里。可以起名（`[character] name = "Claude"`）。

**它有情绪，情绪来自真实数据，不装可爱：**

| 情境 | 判定 | 表情 | 会说的话（第二人称、短句、具体数字、永远向上） |
| --- | --- | --- | --- |
| 专注 | 有回合在进行 | 眯眼敲键盘 | 「在做了，别催。」「第 3 个文件改完了。」 |
| 开心 | 回合结束，测试通过 | ^ ^ 眼 + 小亮点 | 「一次过。」「这把测试全绿。」 |
| 骄傲 | 晋级 / 破纪录 / 单日 ≥ 2 人日 | 星星眼 | 「晋级了，黄金 IV。」「今天顶一个人两天。」 |
| 困 | 0–5 点还在干 | 半睁眼 + zZ | 「凌晨两点，这段我记着。」 |
| 等你 | 60 分钟没动静 | 眼睛往旁边看 + 咖啡 | 「我在，随时开工。」 |
| 想你 | ≥ 14 天没来 | 举着小灯 | 「欢迎回来，灯一直亮着。」 |

台词规则沿用 SPEC §8.5：说产出不说节省，不说教，不提 token 和费用，每句 ≤ 18 字。台词是模板 + 数字，不调用模型；想要更有灵气的日报文案，设置里可开启「让 Claude 写日报」（本地 `claude -p`，只喂汇总数字，不喂代码）。

## 3. 价值分类：做了哪些不同的事

把 12 种任务类型折成 4 类，每类一个颜色，报告里按工时分：

| 类 | 包含 | 颜色 | 一句话 |
| --- | --- | --- | --- |
| 建造 | feature、migration、data、infra | 青绿 `#5b8c7e` | 做出了新东西 |
| 修缮 | bugfix、refactor、config | 琥珀 `#d9955b` | 让旧东西更好 |
| 守护 | test、review | 蓝 `#6f8fc9` | 保证质量 |
| 沉淀 | docs、research | 紫 `#a98fd0` | 写下来、想清楚 |
| 其他 | other | 灰 `#b8b0a2` | 没认出来的 |

已知问题：规则分类器把 78% 的回合判成"其他"（docs/OPEN_QUESTIONS.md 第 21 条）。报告里"其他"照实显示，不藏；时间线上每段用**会话标题**标注（见 §4），所以即使分类没认出来，你也知道那段在做什么。分类器升级（更大的词表 + 看改了什么文件）是下一步。

## 4. 做了哪些事：会话标题和项目名

Claude Code 自己会给每个会话起标题（如「修复添加deepseek后的codex问题」），存在 transcript 里。报告按会话 ID 去 `~/.claude/projects/*/<id>.jsonl` 读这个标题和工作目录的文件夹名，缓存进本地 `session_meta` 表。

隐私边界（改动 SPEC §14）：**项目文件夹名和会话标题只存本地、只进本机的报告**。分享卡默认**不带**它们（`--names` 显式打开才带），永远不上传。prompt、代码、路径仍然一个字不存。

### 周报 `--week`（1080 × 1350）

七天的小柱图（标最高一天）、本周总工时与杠杆、四类占比、做得最多的 3 个会话、段位变化（周一 → 周日）、角色一句周评（「这周三天都在建造，周四收尾。」）。

### 月报 `--month`（1080 × 1920）

日历热力图（每格按工时深浅，周末灰）、月总工时 / 活跃天数 / 最长连续、四类占比、Top 5 会话、段位之路（月初 → 月末）、每天几点开工几点收工的分布（「你最常在 21–24 点开工」）、角色月评。
