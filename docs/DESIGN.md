## 一句话

ShadowCorp 是住在屏幕角落的"你的 Claude"：它记得自己替你干了多少活、这些活请人来做要花多少钱、都当了谁，每天、每周、每月给你写一份好看到能发出去的工作报告。不只是写代码：写文章、做视频、做图、查资料、分析股票都算。

## 1. 钱：请人来做要花多少（v3，2026-10-29）

v2 把 $ 收起来了，因为 $80/小时是拍的数。v3 把它请回来，但换了算法：**每一步按"该请哪种人来做"计时，再按那个职业的真实时薪算钱**。

- 头条是 $：「今天这些活，请人来做要花 $951」。下面一行是工时和杠杆：「17.7 小时的活 · 你花了 1.2 小时 · 杠杆 14.8x」。
- 时薪来源：美国劳工统计局 OEWS 2025 年 5 月全国**时薪中位数**，用 BLS 公共 API 拉取（序列 `OEUN0000000000000<SOC>08`），写在 `assets/occupations.toml`。只算工资，不含福利和公司开销，是偏保守的读法。
- v4（2026-10-29）：**段位和 XP 删掉**，钱是唯一的尺度。长期的感觉来自两件真实的事：**单日纪录**（今天和历史最高的一天比，破了当场庆祝）和**同比**（上周 → 本周、上个月 → 本月）。
- `[value] hourly_rate_usd` 删除（旧配置里留着也没关系，会被忽略）。

### 杠杆 = 经济杠杆（v5，2026-10-29）

用户："这个杠杆可以是经济收益的杠杆，不是时间的杠杆……根据 token 的使用量来算。"

- **杠杆 = 这段时间干出的活值多少 $ ÷ 模型花了多少 $**。分母是按官方 API 价格算的模型花费（用订阅也照这个算，它是"这些 token 按 API 买要多少钱"）。
- 每个回合的 token 来自 agent 自己的日志：Claude Code 每条助手消息带 `model` 和 `usage`（输入、5 分钟 / 1 小时写缓存、读缓存、输出），同一个 message id 写成多行只算一次，子 agent 的 transcript 也算；Codex 每次响应一条 `token_usage_record`（缓存输入包含在输入里、推理包含在输出里），老版本只有 `token_count` 事件就用它的 `last_token_usage`，审查线程也算。按时间落到回合里。
- 单价在 `assets/model_prices.toml`，抄自官方价格页（Anthropic、OpenAI，2026-10-29）。超过长上下文阈值的请求用 `@long` 价（OpenAI 272K 输入、Haiku 5.5 100K）。表里没有的模型（如 `codex-auto-review`）只记 token 不计钱。
- 每个回合结束 15 秒后，守护进程在锁外读日志，生成一条 `usage` 事件（只有数字），入库时算 `turns.cost_usd` 和 `cost` / `cost:<工具>` 计数器；`rebuild` 能复原。
- 出现的地方：结算框和状态栏（本周杠杆）、仪表盘四格（"花 $115 · 15.4x"）、Claude Code 与 Codex（"$5,643 ÷ $258 = 21.9x"）、卡片副标题（"33.6 小时的活 · 模型花费 $115 · 杠杆 15.4x"）、周卡"杠杆"格、`stats` 的"模型花费"行。
- 旧的"时间杠杆"（等价工时 ÷ 你在场的时间）只留给成就判定（L01 等）和"单会话最高时间杠杆"纪录。

## 2. 角色：你的 Claude

不是公司员工，就是 Claude 本人——一个圆滚滚的墨团，两只大眼睛。v4 起它是一只**桌面宠物**：站在小部件卡片上，有自己的透明窗口（只有角色本身接受点击，其余点穿），可以起名（`[character] name = "Claude"`）。

**它一直在干活，而且会换装（v4）：**

- 有回合在跑：坐到小桌前，笔记本屏幕上代码在滚、光标在闪、两只手交替敲；每个子 agent 是身后一个小帮手（最多画 3 个）。
- 回合结算：桌上飘起一张小票「+$78 · 软件工程师」，2.8 秒内上升、淡出，伴一声轻响（Tink；23:00–8:00 静音，菜单可关）。
- 按正在干的活换装（`activity.job`：进行中回合的主要职业，没有就是上一个回合的）：程序员连帽衫 · 网页开发 `</>` 胸针 · 测试工程师放大镜 · 运维安全帽 · 数据分析师图表 · 金融分析师领带 · 研究员圆眼镜 · 文案铅笔 · 翻译「译」气泡 · 平面设计贝雷帽 · 视频剪辑耳机 · 资料录入一摞表格。颜色用 `occupations.toml` 里该职业的色，和仪表盘、卡片一致。仪表盘头像和分享卡上的角色也穿当期主要职业的衣服。
- 没活：呼吸、每 2.5–5.5 秒眨一次眼，端杯咖啡（手里有东西的职业不端）。

- **场景**：每个职业有一个 `scene`（工位 desk、工作室 studio、诊室 clinic、健身房 gym、后厨 kitchen、教室 classroom、法庭 court、实验室 lab、车间 workshop、花园 garden、游戏角 lounge），和一套 `look`（帽子、外套、手里的东西，按部件名画，共约 60 个部件）。

## 3½. 不装钩子也能记（2026-11-02）

为了能把 App 打包给别人（apps/widget/package.sh），新装的机器上什么都不用在 Claude Code、Codex 里装：守护进程第一次启动导入历史，之后跟读两边自己写的记录。Claude Code 的 transcript 一行一行读（backfill.rs `Transcript`，回填也用它），回合在下一句 prompt 时结束；跟读时 Claude `end_turn` 后 20 秒没有新动静就结束（可能被 hook 叫回去接着干），有工具还在跑的等半小时，别的情况安静 10 分钟算结束。装了 Dango 插件的机器（开发机）照旧走钩子，跟读关掉，钩子报过的会话不读，所以不会重复计。

2026-11-04 补上没有钩子时缺的几样（用户：「没有插件就没办法正常显示」）：
- **团子的心情**：以前「最近一次动静」只认钩子送来的事件，没有钩子时团子一直说「我在，随时开工」；现在跟读到的也算（snapshot.rs `activity`）。顺带修好了 Codex：它一直是跟读的，以前也不算。
- **回合马上结算、等你批准**：读 Claude Code 自己的 `~/.claude/sessions/<pid>.json`（claude_tail.rs `live_sessions`）。`status` 在最后一行之后变成 idle 就结算，不用再等 20 秒；`waitingFor` 有值就记一条 `permission_prompt` 通知事件（不存对话框的字），办公室里那只团子站到隔断旁。进程不在、文件读不到就退回老规则。这是 Claude Code 的内部文件，格式可能变；`waitingFor` 在权限弹窗时确实有值这一点还没有用一次真弹窗验证（docs/OPEN_QUESTIONS.md 33）。
- **帮手**：新事件 `subagent_start`（core `Kind::SubagentStart`），会话记录里 Task / Agent 调用发出去时记一条、结果回来时记一条 `subagent_stop`；在干的帮手 = 开始 − 结束（没有开始事件时照旧用 Task 调用 − 结束，钩子那条路不变）。钱不变：子 agent 的 12 分钟仍按 max(调用, 结束) 算一次。
- **结算框**：只有钩子能写进 Claude Code 的界面，没有替代；右键菜单加了「结算时发系统通知」（默认关，打开时向系统要通知权限），标题「+$78 · 软件工程师」，正文今天累计。

## 9. Windows 版（2026-11-08）

用户：「请你再开发个 Windows 版本的 DANGO」。先做 MVP：角落的团子、面板、托盘、安装包；老板人格的故事、报告窗口和 4:5 分享图放第二步。

- **技术栈：Tauri v2**（apps/windows）。macOS 的 apps/widget 是 Swift/AppKit，Windows 上用不了；Tauri 的后端就是 Rust，直接链接 crates/daemon（读 config、写语言、出文字日报都调现成的函数），自带 NSIS 安装包，WebView2 在 Windows 11 自带。没选 Electron（另带一个 Chromium，和 Rust 之间还要一层进程通信）和原生 Win32 / WinUI（面板的排版和动画要重写一遍，没法在 Mac 上看效果）。界面是网页，在 Mac 的浏览器里就能截图对照（CLAUDE.md「Windows 版」）。
- **一个程序两种身份**：`Dango.exe` 不带参数是团子 + 面板 + 托盘；`Dango.exe --daemon` 跑 `daemon::server::run`，和 macOS 的 `dango daemon` 是同一段代码。守护进程放在 GUI 程序里，是因为登录项启动控制台程序会弹一个黑窗口。命令行 `dango.exe`（crates/cli）装在 `bin\`：和 `Dango.exe` 放一起会撞名（磁盘不分大小写，和 macOS 把它放进 Contents/Helpers 是同一个原因）。
- **开机自启：注册表 Run 键**（HKCU，不要管理员权限；没用任务计划，它的「登录时」触发要管理员权限）。两个值：`Dango Daemon` = `"…\Dango.exe" --daemon`（= com.dango.daemon），`Dango` = 团子（= com.dango.widget 的登录项，托盘「登录时自动启动」开关它）。App 每次启动做 macOS `ensureDaemon` 做的事：写登录项（第一次也打开团子的登录启动，团子冒「团子们在翻你的…历史」）、守护进程没在跑就起一个；Run 键没有 launchd 的 KeepAlive，App 每 30 秒看一次 processor.lock，没人拿就再起。
- **守护进程和 CLI 之间**：还是同一个 JSON 行协议、同一个 `daemon.sock` 文件。Windows 10 1803 起支持 AF_UNIX，Rust 标准库没有，用 uds_windows；文件在用户目录里，别的用户打不开（macOS 上是 0600）。
- **路径**：主目录在 Windows 上是 %USERPROFILE%（Windows 不设 HOME），所以 `.claude`、`.codex`、`.dsh`、`.workbuddy-ai` 和数据目录 `.dango` 都在它下面，`DANGO_HOME` 照旧能改。会话记录里的 `C:\…\tests\x.py` 在算职业前把 `\` 换成 `/`，tests/、components/ 这些目录规则才认得；只在 Windows 上换，macOS 的算法一个字节不变。跟读日志靠文件长度和偏移，Windows 上 Rust 打开文件默认允许别人同时写，行为一样。
- **团子和面板**：dango.js 按 apps/widget/assets/dango/dango.json 用部件 PNG 拼团子，逐个移植了 theme.swift 的 `drawPackDango`、`packRoles`、`motion`、`stateExtras`、`officeStatus`、`Appearance.sky`；panel.js 是 `layoutV3`，pet.js 是 `drawCard`，尺寸都照抄（面板 440 宽、团子窗口 230 × 140、团子 84 × 74）。宠物窗口透明、置顶、不进任务栏；只有团子那块接鼠标：后台每 50 毫秒看一次光标，在团子外面时整个窗口点击穿透（macOS 是 `ignoresMouseEvents` 跟着全局鼠标走）。面板失焦就收起（macOS 用全局点击监听）。外观（跟随系统 / 浅色 / 深色）存在 App 自己的 prefs.json，深色是白团子 B01W，和 macOS 一样只管团子、面板和办公室。语言和 macOS 一样六种（中英韩日法西）：托盘菜单走 `Lang::t`，页面的 `L(中, 英)` 对另外四种查同一份 assets/i18n 表。
- **这一版没有的**（第二步）：老板人格故事和总卡窗口、16 型图鉴、报告窗口、4:5 分享图（面板「分享日报」先把 `dango report` 的文字日报放进剪贴板，不带会话标题和项目名）、结算提示音和系统通知。`dango card` 在 Windows 上会说还不能出分享图。
- **验证**：这台 Mac 上只能交叉类型检查（tools/windows_check.sh）和在浏览器里看界面；真编译、测试和安装包在 GitHub Actions 的 windows-latest 上（.github/workflows/windows.yml）。没在真 Windows 上跑过的地方记在 docs/OPEN_QUESTIONS.md 35–41。
