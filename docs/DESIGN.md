# ShadowCorp 设计稿 v6 — 你的 Claude，和它的工作日报

2026-10-29。替代 docs/SPEC.md 第 1、6–10 节的"影子公司"设定。v3 把"每回合多少分钟"从 SPEC §5.3 的任务类公式换成按职业计时（§1、§3），日 / 周封顶和 XP 不变。

## 一句话

ShadowCorp 是住在屏幕角落的"你的 Claude"：它记得自己替你干了多少活、这些活请人来做要花多少钱、都当了谁，每天、每周、每月给你写一份好看到能发出去的工作报告。不只是写代码：写文章、做视频、做图、查资料、分析股票都算。

## 1. 钱：请人来做要花多少（v3，2026-10-29）

v2 把 $ 收起来了，因为 $80/小时是拍的数。v3 把它请回来，但换了算法：**每一步按"该请哪种人来做"计时，再按那个职业的真实时薪算钱**。

- 头条是 $：「今天这些活，请人来做要花 $951」。下面一行是工时和杠杆：「17.7 小时的活 · 你花了 1.2 小时 · 杠杆 14.8x」。
- 时薪来源：美国劳工统计局 OEWS 2025 年 5 月全国**时薪中位数**，用 BLS 公共 API 拉取（序列 `OEUN0000000000000<SOC>08`），写在 `assets/occupations.toml`。只算工资，不含福利和公司开销，是偏保守的读法。
- v4（2026-10-29）：**段位和 XP 删掉**，钱是唯一的尺度。长期的感觉来自两件真实的事：**单日纪录**（今天和历史最高的一天比，破了当场庆祝）和**同比**（上周 → 本周、上个月 → 本月）。
- `[value] hourly_rate_usd` 删除（旧配置里留着也没关系，会被忽略）。

### 杠杆 = 经济杠杆（v5，2026-10-29）

用户："这个杠杆可以是经济收益的杠杆，不是时间的杠杆……根据 token 的使用量来算。"

- **杠杆 = 这段时间干出的活值多少 $ ÷ 模型花了多少 $**。分母是按官方 API 价格算的模型花费（用订阅也照这个算，它是"这些 token 按 API 买要多少钱"）。
- 每个回合的 token 来自 agent 自己的日志：Claude Code 每条助手消息带 `model` 和 `usage`（输入、5 分钟 / 1 小时写缓存、读缓存、输出），同一个 message id 写成多行只算一次，子 agent 的 transcript 也算；Codex 每次响应一条 `token_usage_record`（缓存输入包含在输入里、推理包含在输出里），老版本只有 `token_count` 事件就用它的 `last_token_usage`，审查线程也算。按时间落到回合里。
- 单价在 `assets/model_prices.toml`，抄自官方价格页（Anthropic、OpenAI，2026-10-29）。超过长上下文阈值的请求用 `@long` 价（OpenAI 272K 输入、Haiku 5.5 100K）。表里没有的模型（如 `codex-auto-review`）只记 token 不计钱。
- 每个回合结束 15 秒后，守护进程在锁外读日志，生成一条 `usage` 事件（只有数字），入库时算 `turns.cost_usd` 和 `cost` / `cost:<工具>` 计数器；`rebuild` 能复原。
- 出现的地方：结算框和状态栏（本周杠杆）、仪表盘四格（"花 $115 · 15.4x"）、Claude Code 与 Codex（"$5,643 ÷ $258 = 21.9x"）、卡片副标题（"33.6 小时的活 · 模型花费 $115 · 杠杆 15.4x"）、周卡"杠杆"格、`stats` 的"模型花费"行。
- 旧的"时间杠杆"（等价工时 ÷ 你在场的时间）只留给成就判定（L01 等）和"单会话最高时间杠杆"纪录。

## 2. 角色：你的 Claude

不是公司员工，就是 Claude 本人——一个圆滚滚的墨团，两只大眼睛。v4 起它是一只**桌面宠物**：站在小部件卡片上，有自己的透明窗口（只有角色本身接受点击，其余点穿），可以起名（`[character] name = "Claude"`）。

**它一直在干活，而且会换装（v4）：**

- 有回合在跑：坐到小桌前，笔记本屏幕上代码在滚、光标在闪、两只手交替敲；每个子 agent 是身后一个小帮手（最多画 3 个）。
- 回合结算：桌上飘起一张小票「+$78 · 程序员」，2.8 秒内上升、淡出，伴一声轻响（Tink；23:00–8:00 静音，菜单可关）。
- 按正在干的活换装（`activity.job`：进行中回合的主要职业，没有就是上一个回合的）：程序员连帽衫 · 网页开发 `</>` 胸针 · 测试工程师放大镜 · 运维安全帽 · 数据分析师图表 · 金融分析师领带 · 研究员圆眼镜 · 文案铅笔 · 翻译「译」气泡 · 平面设计贝雷帽 · 视频剪辑耳机 · 资料录入一摞表格。颜色用 `occupations.toml` 里该职业的色，和仪表盘、卡片一致。仪表盘头像和分享卡上的角色也穿当期主要职业的衣服。
- 没活：呼吸、每 2.5–5.5 秒眨一次眼，端杯咖啡（手里有东西的职业不端）。
- 动画只在有事发生时 24 fps，闲时 4 fps。

**它有情绪，情绪来自真实数据，不装可爱：**

| 情境 | 判定 | 表情 | 会说的话（第二人称、短句、具体数字、永远向上） |
| --- | --- | --- | --- |
| 专注 | 有回合在进行 | 眯眼敲键盘 | 「在当程序员，别催。」「带着 2 个帮手在干。」 |
| 开心 | 回合结束，测试通过 | ^ ^ 眼 + 小亮点 | 「一次过。」「这把测试全绿。」 |
| 骄傲 | 破单日纪录 / 单日 ≥ 2 人日 | 星星眼 + 金色星星 | 「今天破了单日纪录。」「今天顶一个人干两天。」 |
| 困 | 0–5 点还在干 | 半睁眼 + zZ | 「凌晨两点，这段我记着。」 |
| 等你 | 60 分钟没动静 | 眼睛往旁边看 + 咖啡 | 「早。我在，随时开工。」「不早了，要干就快。」 |
| 记得 | 回合刚结束 / 周四后本周比上周多 20% / 第 7、30、100… 天 | 开心 | 「刚干了 1.2h 的程序员活，值 $78。」「这周比上周多 $600。」「一起干活的第 30 天。」 |
| 想你 | ≥ 14 天没来 | 举着小灯 | 「欢迎回来，灯一直亮着。」 |

台词规则沿用 SPEC §8.5：说产出不说节省，不说教，不提 token 和费用，每句 ≤ 18 字。台词是模板 + 数字，不调用模型；想要更有灵气的日报文案，设置里可开启「让 Claude 写日报」（本地 `claude -p`，只喂汇总数字，不喂代码）。

## 3. 都当了谁（替代 v2 的"建造 / 修缮 / 守护 / 沉淀 / 其他"）

v2 的四类是按 prompt 关键词分的，78% 落进"其他"，而且只认得写代码。v3 不再看 prompt 分类，而是看**每一步实际做了什么**，归到 12 种职业：

| 职业 | SOC | 时薪 | 什么步骤算它的 | 估多少分钟 |
| --- | --- | --- | --- | --- |
| 程序员 | 15-1252 | $65.38 | 改代码文件；git commit / merge；编译 | 2.5 + 0.45 × 行数^0.8；提交 20；编译 2 |
| 网页开发 | 15-1254 | $47.49 | 改 html / css / tsx / vue … | 同上 |
| 测试工程师 | 15-1253 | $50.14 | 改测试文件；跑测试 | 同上；每次跑 10 |
| 运维 | 15-1244 | $47.66 | 改配置；装依赖、launchctl、docker | 5 |
| 数据分析师 | 15-2051 | $57.80 | curl / sqlite / pandas；跑 python；数据库类连接器 | 6 / 4 / 10 |
| 金融分析师 | 13-2051 | $49.40 | 金融数据连接器；或者回合在聊股票时的研究和数据步骤 | 10 |
| 研究员 | 13-1161 | $37.87 | 网页搜索 5、读网页 10、浏览器读页面 5；纯聊天回合 | 5 |
| 文案写作 | 27-3043 | $36.98 | 写 md / txt / docx … | 字数 ÷ 500 字/小时，至少 3 |
| 翻译 | 27-3091 | $28.93 | 回合要求翻译时的写作步骤 | 同上 |
| 平面设计 | 27-1024 | $30.27 | 产出 svg / png …；magick / inkscape | 30 / 15 |
| 视频剪辑 | 27-4032 | $36.26 | ffmpeg / moviepy / remotion；配音 tts；whisper 字幕；yt-dlp | 15 / 15 / 20 / 5 |
| 资料录入 | 43-9021 | $19.88 | OCR（tesseract、自写 ocr 脚本） | 15 |

一个回合 = 各步之和 + 5 分钟（读需求、汇报）+ 每个子 agent 12 分钟，都记在本回合最主要的职业上；单回合封顶 6 小时，超了按比例一起缩。字数只数不存；命令只看关键词，不存。规则在 `crates/core/src/occupation.rs`，12 个黄金回合在 `fixtures/scoring/golden.toml`。

拿真实历史验证（2026-10，130 个回合）：程序员 25.6h、文案写作 28.6h、视频剪辑 26.0h、数据分析师 20.1h、研究员 10.3h …… 合计 129h，$6,054。

### 话题 → 职业和场景（v6，2026-10-29）

用户："我在 claude code 或者 codex 里面问健康的内容，这个小人就会显示一个医生在医院里面工作……问健身的内容，这个小人就在举铁……按照 BLS 规定的很多不同的职业来设计。"

- **职业从 12 种扩到 49 种**，都按 BLS SOC 编码取 2025 年 5 月时薪中位数（同一个 API、同一个序列格式，2026-10-29 拉取）：医生、营养师、药剂师、心理咨询师、兽医、健身教练、厨师、家教、数学家、律师、化学家、生物学家、物理学家、经济学家、建筑师、机械 / 电气工程师、电工、木工、汽修、水管工、园艺师、育儿顾问、会计、经理、产品经理、人事、销售、房产经纪、旅行顾问、网络安全、UX、摄影师、室内设计、音乐人、服装设计师、造型师……（只有年薪的职业不收，如中小学老师 → 用家教 25-3041；21-1014 无数据 → 21-1018）。
- **话题**：每条 prompt 在本机按关键词打分，命中一个强词 2 分、弱词 1 分，满 2 分才算有话题，同分取表里靠前的职业（技术类在前）。共 2690 个中英文关键词；英文按整词匹配（`cpu` 不会命中 `gpu`），中文按子串。prompt 本身不落盘，只存职业 id（`payload.topic`）。金融类连接器直接算 `fin`。
- 话题怎么改账：回合里的**研究**步骤（搜索、读网页）算给话题职业；**写作**在翻译话题下算翻译；**数据脚本**在 `absorbs_data` 的职业（金融、会计、数学、理科、工程）话题下算给它。**纯聊天回合**按话题职业的 `consult` 分钟计（5–30 分钟，默认研究员 5 分钟）。改代码、跑测试等仍按步骤本身归类——话题不会把程序员的活记到医生头上。
- **场景**：每个职业有一个 `scene`（工位 desk、工作室 studio、诊室 clinic、健身房 gym、后厨 kitchen、教室 classroom、法庭 court、实验室 lab、车间 workshop、花园 garden、游戏角 lounge），和一套 `look`（帽子、外套、手里的东西，按部件名画，共约 60 个部件）。
- **在干活时**：工位职业照旧敲笔记本；其他场景各有动作——举杠铃、看心电监护、颠锅、在白板上写、敲法槌、烧瓶冒泡、抡锤溅火星、浇苗、搭积木；工作室按手里的东西分：弹吉他飘音符、相机闪光、剪辑时间线、裁衣、写稿 / 双页翻译、画架上一笔一笔。干活时双手在器材上，所以手持道具收起来，帽子和衣服还在。
- 旧事件里的 `finance: true` 仍读成话题 `fin`（只读不写），这样 `rebuild` 不会让金融回合变便宜；旧的 `translate` 标记不再读（它只会把写作改成更便宜的翻译）。

## 4. 做了哪些事：会话标题和项目名

Claude Code 自己会给每个会话起标题（如「修复添加deepseek后的codex问题」），存在 transcript 里。报告按会话 ID 去 `~/.claude/projects/*/<id>.jsonl` 读这个标题和工作目录的文件夹名，缓存进本地 `session_meta` 表。

隐私边界（改动 SPEC §14）：**项目文件夹名和会话标题只存本地、只进本机的报告**。分享卡默认**不带**它们（`--names` 显式打开才带），永远不上传。prompt、代码、路径仍然一个字不存。

## 6. 小部件

- 收起时只有宠物（§2），脚下一个小标签：`今日 $1,342`；悬停换成台词；破纪录闪 `单日新高 ✦`。卡片（累计 $、进度条）删掉了——用户觉得累赘，累计和纪录在仪表盘里。
- 办公室（仪表盘第一块，v6）：**一间屋 + 舞台 + 茶水间**。左边茶水间（门、咖啡机、沙发），中间舞台，右角窗户和花。人是最近 7 天干过活的职业（`office[]`，最多 8 个，按"在干 → 这周 $"排）。
  - 在干的职业站上舞台，身后换成它的场景（诊室有红十字、帘子和视力表，健身房有镜子和哑铃架，后厨有油烟机和瓷砖……），头顶挂场景名牌，一束聚光灯；帮手在旁边。舞台最多两人，各占半边；第三个起在舞台前沿写"X 也在干"。没人干时舞台空着："有活就有人上来"。
  - 其他人在茶水间摸鱼，四个位置：咖啡机前（< 15 分钟：端杯喝，冒热气）、沙发两个座（刷手机；两人都醒着就聊天冒气泡；> 2 小时睡着，闭眼飘 z）、右角（看窗外 / 浇花）。想做的事每 3 分钟换一次，换了位置就**走过去**（40 点/秒，一跳一跳）。闲人多于四个时每 2 分钟轮换：一个走到门口出去，下一个从门口进来，门随之开关。
  - 职业轮到干活就从茶水间走上舞台，干完走回去；名字在地上分两行排开，从不叠在一起。窗外天色按本机时间，白天有云飘过。不随 agent 切换过滤（职业与 agent 无关）。
- 宠物干活时同样按场景动作（没有背景），手持道具收起；闲时拿着自己的道具。
- 仪表盘：头像（穿着当前职业）+ 累计 $ + 在当谁 + 一句话；今日 / 纪录进度 + 一起干活第几天；全部 / Claude Code / Codex 与 1 / 7 / 30 天两组切换；四格；产出图（1 天按小时，7 / 30 天按日）；都当了谁（可展开）。最近回合不再显示（宠物的小票就是最近回合）。
- 结算框：`+$78  1.2h · 程序员 · 测试工程师`，第二行 `今日 $327  本周 $1,240 · 杠杆 7.1x`，第三行 `累计 $11,724 ▓▓▓░░ 单日纪录 $1,742`。
- 状态栏：`▮ $11,846 · 今日 $1,342 · 本周 $3,595 · 杠杆 8.6x`。
